# Playthroughs played by agents

One folder per game, each the complete record of a game played by agents: the script the page is built from (`game.py`), every prompt and reply (`log/`, indexed in `log.md`), the ledger, the diaries, the narration, the state snapshots and the chapter handoffs. The code and notes for playing a game are in `../playthrough-sim/agents/`. The games listed in `build_real.py` are built into `../playthroughs-real.html`.

| Folder | Game | On the page |
|---|---|---|
| `peasant-failure/` | "Peasant Failure": the peasant game's five-player table, 8 years. Ends in an economic collapse after the population triples. See its `REPORT.md`. | yes |
| `trial-year1/` | A first trial year of the same table, played before the tools were fixed. Kept for reference. | no |

The records were written while these games lived in `playthrough-sim/pilot/`, so older logs and handoffs still mention that path.
